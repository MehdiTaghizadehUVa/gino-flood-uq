# Triage Labels

Use these default labels:

- `needs-triage`: maintainer needs to evaluate.
- `needs-info`: waiting on reporter.
- `ready-for-agent`: fully specified and safe for an AFK agent.
- `ready-for-human`: requires human judgment or manual work.
- `wontfix`: will not be actioned.

Use exactly one category label, `bug` or `enhancement`, plus one state label when publishing or triaging issues.
