# Domain Docs

This repo uses a single-context domain layout:

- `CONTEXT.md`: shared domain glossary and serving concepts.
- `docs/adr/`: architectural decision records for durable deployment decisions.

When using `diagnose`, `tdd`, `improve-codebase-architecture`, `to-prd`, `to-issues`, or `triage`, read `CONTEXT.md` first and check relevant ADRs before proposing architecture changes.
